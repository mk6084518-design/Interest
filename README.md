## 🚀 Overview

**Interest** is a clean and responsive web application built with React and Vite. It is designed as a fast, flexible foundation for creating an engaging interest calculator, financial dashboard, or educational experience.

## 🛠️ Tech stack

- **React** — Component-based UI
- **Vite** — Fast development and production builds
- **ESLint** — Consistent, maintainable code
- **CSS** — Responsive visual design

## ⚡ Getting started

### Prerequisites

- Node.js 18+
- npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/mk6084518-design/Interest.git
cd Interest
npm install
npm run dev
```

Open the local URL shown in your terminal to view the application.

## 📜 Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Check the code with ESLint |
