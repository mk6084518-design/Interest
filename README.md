## 🚀 Overview

**Interest** is a responsive media search platform for finding and exploring entertainment content. Search for media, browse results, open detailed information, and keep track of the content that interests you through a focused, easy-to-use interface.

The application is designed to make media discovery quick and enjoyable across desktop and mobile devices, with a modern React interface and a fast Vite-powered development experience.

🔗 **Try Interest live:** [https://interest-i3s1.onrender.com/](https://interest-i3s1.onrender.com/)

## ✨ Features

- 🔎 Search for media from a single, intuitive search experience
- 🎬 Browse media results in a clean, responsive layout
- 📖 View additional information about selected media
- 🧭 Navigate smoothly between search and detail views
- ⚡ Fast client-side interactions powered by React
- 📱 Responsive design for desktop, tablet, and mobile screens
- 🔔 User-friendly feedback and notifications

## 🛠️ Tech stack

- **React** — Component-based user interface
- **Vite** — Fast development server and production build tool
- **React Router** — Client-side navigation
- **Redux Toolkit** — Predictable application state management
- **Axios** — HTTP requests for media data
- **Tailwind CSS** — Responsive styling and UI layout
- **React Toastify** — In-app notifications and feedback
- **ESLint** — Consistent and maintainable code

## ⚡ Getting started

### Prerequisites

- Node.js 18 or newer
- npm, pnpm, or yarn

### Installation

```bash
git clone https://github.com/mk6084518-design/Interest.git
cd Interest
npm install
npm run dev
```

Open the local URL shown in your terminal to use the application.

## 📜 Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create an optimized production build |
| `npm run preview` | Preview the production build locally |
| `npm run lint` | Check the code with ESLint |
